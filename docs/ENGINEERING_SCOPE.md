# Validation scope

The controller, HMI, process simulation, fault injection and FAT behavior in this repository were exercised in the portfolio/lab simulation environment.

The TIA project also contains the documented hardware/network/drive/interface engineering shown in the repository: CPU 1511C-1 PN, ET 200SP, PROFINET, CM 1542-5 / PROFIBUS DP, SINAMICS G120C / Startdrive, Siemens `SinaSpeed`, and the PLC-side OPC UA mapping.

Physical plant commissioning requires the corresponding field hardware and is outside the simulation evidence presented here.
